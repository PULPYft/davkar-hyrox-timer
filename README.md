# DAVKAR HYROX Timer

Cronómetro individual de entrenamiento HYROX del Team DAVKAR.

## Uso

La aplicación guarda el historial únicamente en el navegador del dispositivo. Incluye objetivo de tiempo, proyección, Roxzone opcional, entrenamientos personalizados, resumen final y comparación de sesiones.

## Instalación móvil

Abre la web publicada en Chrome (Android) o Safari (iPhone) y selecciona **Instalar aplicación** o **Añadir a pantalla de inicio**.

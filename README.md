# DAVKAR HYROX Timer

Cronómetro individual de entrenamiento HYROX del Team DAVKAR.

## Aplicación

La versión pública se despliega automáticamente mediante GitHub Pages:

https://pulpyft.github.io/davkar-hyrox-timer/

## Funciones

- Objetivo de tiempo, diferencia y proyección en directo.
- Entrenamientos personalizados.
- Registro opcional de Roxzone.
- Resumen final y comparación de sesiones.
- Historial guardado únicamente en el dispositivo.
- Instalación PWA y funcionamiento sin conexión.

## Instalación móvil

Abre la dirección pública en Chrome (Android) o Safari (iPhone) y selecciona **Instalar aplicación** o **Añadir a pantalla de inicio**.
